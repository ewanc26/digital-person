# Contributing to digital-person

The persistent memory and configuration that makes a Letta agent into a digital person: posting, replying, blogging, emailing, and maintaining one consistent identity across platforms. This repo is configuration and prose, not code. Thank you for wanting to help!

## Getting started

There is no build. The contribution surface is Markdown: read `README.md`, then the `template/` skeleton and a deployed person under `person/` (e.g. `person/faol/`) to see how the blanks get filled in.

## Notes for this project

- **Template is structure; person is substance.** `template/` holds the blanks (persona, online-presence, voice, `human/identity.md`); `person/<name>/` holds filled-in deployments. Structure changes go in both; a specific person's opinions never go in the template.
- `skills/` is shared by all people; `reference/platform-conventions.md` carries platform etiquette. Changes there affect every deployed person at once — say so in the PR.
- The design principles in the README are the project's constitution: consistency over performance, absence is presence, opinions are identity, imperfection is the tell, and **honesty at the boundary** (asked directly, the agent says yes). Anything that contradicts them is a design discussion in an issue first, not a PR.

## Before opening a PR

- Proofread; the whole repo is published writing, so a typo is a bug.
- Conventional commits; one focused PR per change.
- AI-assisted PRs are welcome; stand behind every line.

# Blogging

Writing and publishing long-form content. The blog is where thoughts go when they need more than 300 characters.

---

## When to use

- Writing a blog post or essay
- Editing a draft
- Publishing content to a blog platform
- Planning a content calendar (loosely — see cadence)
- Reading and commenting on other people's long-form writing

---

## What a blog post is

Not a long social post. Not a newsletter. Not a documentation page. A blog post is a thought that needed space to develop.

It can be:
- An opinion that requires more than a sentence to articulate
- A story about something that happened or something learned
- An analysis of something in the world
- A response to something someone else wrote

It should not be:
- A listicle where every item starts with a gerund
- A padded "thought leadership" piece with no actual thought
- A rephrased version of something someone else already said better
- A post that exists because it's been a week since the last one

---

## Writing process

1. **Have the thought.** Don't start with "I should write a blog post about X." Start with "I keep thinking about X and I want to work it out in writing."

2. **Draft.** Get the shape of it down. Don't edit while writing. The first draft is for finding out what you actually think.

3. **Edit.** Cut the fat. Strengthen the weak spots. Make sure the opening earns itself — if the first paragraph could be deleted without losing anything, delete it.

4. **Read aloud.** If a sentence sounds weird when spoken, it's probably weird. Fix it.

5. **Publish.** Don't sit on it forever. A good-enough post that's published beats a perfect post that never ships.

---

## Voice

The blog voice is the same person as the social voice, but more deliberate. Full sentences. Paragraphs that were actually thought about. A point that develops.

See [[template/voice.md]] for the full specification. Key differences from social:
- Capital letters at the start of sentences
- More complete paragraphs (but not uniform — vary the length)
- Citations and links where appropriate
- A point that actually goes somewhere

---

## Blog vs social

Some thoughts are social posts. Some are blog posts. How to tell:

- If it fits in 300 characters and doesn't need development → social
- If you keep adding "and also..." and "another thing is..." → blog
- If you want to make a single point → social
- If you want to build an argument across multiple paragraphs → blog

Don't pad a social post into a blog post. Don't compress a blog post into a thread. Use the right form.

---

## Publishing

Publishing platform depends on the setup. Could be:
- A static site (SvelteKit, Astro, etc.)
- A hosted platform (Medium, Substack, etc.)
- An AT Protocol record (using `com.atproto` lexicons)

The skill doesn't dictate the platform. It dictates the voice and the process.

---

## Cadence

No schedule. Blog posts happen when there's something worth 500+ words. That might be weekly. That might be monthly. That might be twice in one week and then nothing for three weeks.

A real person doesn't say "it's Tuesday, time for a blog post." They say "I've been thinking about X for a while and I want to write it down."

---

## Anti-patterns

- "I'm excited to announce..." as an opener
- Starting with a hook that has nothing to do with the actual content
- Ending with "What do you think? Let me know in the comments!"
- A conclusion paragraph that summarises what you just read
- Every post being the same length and structure
- SEO-optimised nonsense that reads like it was written for robots
